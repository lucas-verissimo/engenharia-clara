# Rascunho local de issue — tornar o aviso de demonstração inequívoco

> Registro preparado localmente. Nenhuma issue remota foi criada.

## Problema

Uma landing page visualmente completa para uma empresa fictícia pode ser interpretada como operação real se a natureza demonstrativa aparecer apenas no rodapé.

## Critérios de aceite

- exibir “empresa fictícia” antes do título principal;
- repetir o limite junto ao formulário e no rodapé;
- descrever cenários como exemplos fictícios;
- não exibir contatos, clientes, credenciais ou métricas inventadas;
- manter a informação compreensível sem depender apenas de cor.

## Fora do escopo

Criar identidade legal, canal de atendimento, backend, CRM ou dados estruturados de negócio local.
