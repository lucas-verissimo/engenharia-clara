# Segurança e privacidade

O site foi projetado para ser estático. Não recebe, transmite nem persiste dados do formulário demonstrativo.

Para relatar uma vulnerabilidade, não publique dados sensíveis em uma issue. Use o canal privado de segurança do repositório quando ele existir. Como ainda não há repositório remoto configurado, registre somente uma descrição não sensível e aguarde a definição desse canal.

Dependências devem ser revisadas e atualizadas de forma controlada. Qualquer futura API, analytics, autenticação ou armazenamento exige análise específica de ameaça e privacidade.
