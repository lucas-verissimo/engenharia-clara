# Como contribuir

Este é um projeto demonstrativo de portfólio. Sugestões são bem-vindas quando preservam a transparência do conteúdo e a natureza estática da aplicação.

1. Abra uma issue descrevendo problema, motivação e critério de aceite.
2. Crie uma branch curta a partir de `main`.
3. Altere conteúdo central em `src/content` e mantenha componentes focados em apresentação.
4. Execute lint, tipos, testes, build e testes de navegador.
5. Abra um pull request com antes/depois, riscos e plano de reversão.

Não adicione dados de pessoas ou empresas reais, rastreamento, integrações externas ou coleta de formulário sem uma decisão arquitetural e revisão de privacidade.
